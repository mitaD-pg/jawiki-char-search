# Wikipedia 文字種パターン検索

Wikipedia 日本語版の見出し語（記事タイトル）を、**文字種の並び**で検索する Web アプリ（PWA）です。
「漢字・かな・カナ・数字・英字・記号・空白」の並びパターンや、特定の文字を混ぜた条件でタイトルを探せます。

- 例：`漢 あ 漢 あ @`（漢字・ひらがな・漢字・ひらがな・記号）→ 「君の名は。」など
- 例：`君 あ 漢 あ @`（先頭だけ「君」固定）→ 「君の名は。」

オフライン対応。ホーム画面に追加すればアプリのように使えます。

## 使い方

1. **文字種パレット**のボタンで型（灰色チップ）を並べる
2. そのまま文字を打てば**リテラル（その文字そのもの）**として条件に入る
3. **検索**を押す（結果のタイトルはタップでコピー）

### 検索モード
- **完全一致**：型チップ＋リテラル文字でタイトル全体が一致するものを探す
- **正規表現**：文字種の並びに対する正規表現（例：`[漢]{2,}[あ]+`）

### 文字種記号
| 記号 | 意味 |
|---|---|
| `あ` | ひらがな |
| `ア` | カタカナ |
| `漢` | 漢字 |
| `1` | 数字（半角・全角） |
| `A` | 英大文字（半角・全角） |
| `a` | 英小文字（半角・全角） |
| `␣` | 空白（半角・全角。元データの語間スペース含む） |
| `@` | その他の記号 |

> 補足：Wikipedia は記事タイトルの先頭を必ず大文字にするため、英字だけの語は `Aaaa…`（先頭大文字）の並びになります。

## データ出典・ライセンス

[`jawiki-latest-all-titles-in-ns0`](https://dumps.wikimedia.org/jawiki/latest/) を元に、検索用の索引へ加工して同梱しています。

## 技術メモ

- 完全クライアントサイド（サーバー不要）。検索は端末内で完結。
- 高速化のため、署名（文字種の並び）ごとにタイトルをまとめた**連結索引**を事前生成し、gzip 圧縮 JSON（`data/index.json.gz`）として同梱。
- PWA（manifest＋Service Worker）でオフライン動作。
- ※ データ展開に `DecompressionStream` を使うため、iOS は 16.4 以降が必要。

### ローカルで動かす
```sh
# このフォルダで簡易サーバーを起動
python -m http.server 8765
# ブラウザで http://localhost:8765 を開く
```

### データ更新
新しいダンプから索引を作り直し、`data/index.json.gz` を差し替えて再デプロイします。
